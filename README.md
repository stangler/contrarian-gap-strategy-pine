# Contrarian Gap Strategy — PineScript v6 ストラテジー

## 概要

5分足チャートで陰線が連続した後、次の足の始値でロングエントリーする逆張り手法。
陰線本数・TP/SL・ナンピン幅・取引時間帯はすべてインプットで変更可能。デイトレ専用（大引けで強制決済）。

## エントリー条件

- 時間足: 5分足
- 方向: ロング（買い）
- 条件: 直近N本がすべて陰線（`close < open`）※N は可変
- エントリー: 条件成立バー確定後、次の足の始値で即執行

## ナンピン

エントリー後、下落が続く場合に最大2回ナンピンを実施。

| 回数 | 発動条件 | 備考 |
|------|---------|------|
| ナンピン1 | 初回エントリーから -10Tick | 1回のみ |
| ナンピン2 | ナンピン1からさらに -10Tick | 1回のみ |

## 決済条件

- **TP**: 平均取得価格 + Tick数（ナンピン後は平均値が下がるため自動調整）
- **SL**: ナンピン2発動価格からさらに -10Tick（固定）
- **大引け強制決済**: 15:25バー（15:30大引け）で未決済ポジションを強制クローズ

## インプット設定

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| TP (平均取得価格 + Tick数) | 5 | 利確幅（平均取得価格基準） |
| SL (ナンピン2からTick数) | 10 | 損切幅（ナンピン2価格基準） |
| ナンピン1 下落Tick（初回から） | 10 | ナンピン1発動Tick |
| ナンピン2 追加下落Tick（ナンピン1から） | 10 | ナンピン2発動Tick |
| 陰線本数 | 4 | 連続陰線の判定本数（2〜6） |
| 事前アラート（N-1本陰線） | ON | N-1本陰線確定時アラート |
| 取引開始 時/分 | 9:00 | エントリー許可開始時刻 |
| 取引終了 時/分 | 15:30 | エントリー許可終了時刻 |
| 開始日 | 2026-04-01 | バックテスト開始日 |
| 終了日 | 2026-04-24 | バックテスト終了日 |

**デフォルト値でのSL位置例（初回エントリー = 100円）:**

- 初回エントリー: 100.00円
- ナンピン1: 99.90円（-10Tick）
- ナンピン2: 99.80円（-20Tick）
- SL: 99.70円（-30Tick）

## 可視化

- 🟢 緑の三角: エントリーシグナル発生箇所（期間内・取引時間内のみ）
- 🟠 オレンジの三角: 事前シグナル発生箇所（N-1本陰線確定）
- 緑のライン: 現在のTP価格
- 赤のライン: 現在のSL価格
- グレー背景: バックテスト対象外期間

## アラート機能

`alert()` 関数を使用。事前アラートのみ実装。インプットでON/OFF可能。

| アラート | 発火条件 | メッセージ例 |
|---------|---------|------------|
| 事前アラート | N-1本陰線確定 | `ズレ手法: 186A 陰線N-1本確定。次の陰線でエントリー候補。` |

### アラート設定手順

1. チャート上部「アラートを作成」
2. 条件 → 「ズレ手法」を選択
3. 「alert()関数の呼び出し」を選択
4. **「バーの終値」を選択**（未確定バーでの誤発火防止）
5. 「作成」で保存

## 使い方

1. TradingView でチャートを5分足に設定
2. Pine エディタにコードを貼り付け
3. 「追加」ボタンでチャートに適用
4. 設定パネルから各パラメータを調整
5. ストラテジーテスターでバックテスト結果を確認

## 評価指標の目安

| 指標 | 目安 |
|------|------|
| プロフィットファクター | 1.5以上（2以上で優秀） |
| 最大ドローダウン | 純利益の30%以内 |
| トレード数 | 20以上（統計的信頼性） |
